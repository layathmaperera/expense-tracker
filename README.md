# 💰 Expense Tracker (Python)

A simple **Python-based Expense Tracker** application.  
It allows you to add expenses, view your balance, and manage transactions easily.

---

## 🚀 Features
- Add new income and expenses
- View all transactions
- Calculate balance, income, and expenses
- Store data in a database or file
- Simple and clean UI

---

## 🛠️ Technologies Used
- **Python 3.13.7**
- **Flask** (for backend web framework)
- **SQLite** (default database, can be replaced with MySQL/PostgreSQL)
- **HTML + CSS + JavaScript** (for frontend)
